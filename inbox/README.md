# inbox（秘書以外が書く唯一の場所）

- ほかの AI（claude.ai のチャットなど）で決めたこと、手で書いたメモは、ここに1ファイルずつ置く（`YYYY-MM-DD-<題名>.md`）
- 秘書は会話の最初に、ここの直下にあるファイルを処理し、`done/<年月>/` へ `git mv` する。処理＝status や knowledge に反映すること
- ここに秘密（パスワード・認証の URL）を書かない
- 型は `_template.md`。秘書は中身を「係を増やす／知識／進み具合／しくみを変える」の4種類に振り分ける（CLAUDE.md）。`_` で始まるファイルと README は未処理に数えない
