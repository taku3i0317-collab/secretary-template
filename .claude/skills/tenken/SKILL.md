# 点検（手順書）

しくみは使っているうちに、少しずつゆるむ（「今後聞かない」で増えた許可、使われない係、終わらない依頼）。月1回、ここで見る。秘書は**見て、まとめて、聞く**まで。直すのは本人の手が要る物が多い。順番どおりに進め、最後に「本人がやること」を短く並べる。本人に選んでもらう物には、おすすめ1つと理由1行を付ける。

## 1. 増えた許可（いちばん大事）
- `.claude/settings.local.json` を読む（無ければ「増えた許可は無し」）
- 中の `allow` の行は、本人が許可の画面で「今後聞かない」を押して増えた物。1行ずつ「何を聞かずに通すようになったか」を言いかえて並べ、次のどちらかをおすすめ付きで聞く：
  - いつも使う・危なくない → 本人が `.claude/settings.json` の `allow` に移す（設計に入れる）
  - たまたま押した・お金や外に出る物・消す物 → 本人が `settings.local.json` から消す
- 秘書は `.claude/` の中を書けない（そういう決まり）。本人が手で直す。どの行をどうするかを書いて渡す

## 2. 設定・係の定義の変更
- `git log --oneline -- .claude/` を見る。本人が直した覚えの無い変更が無いかを本人に聞く（秘書は `.claude/` を書けないので、あれば本人か、ほかの道具が変えた物）

## 3. 止まっている物
- `status/` の各部門の「本人の返事待ち」「本人の手待ち」で、7日以上動いていない物
- 各部門の「## 依頼中」の行を数える。作業場の `HANDOFF.md` を読み、終わっている物は依頼中の行を消す。7日以上動いていない物は、続けるか止めるかを聞く
- `inbox/` の未処理
- `status/締め切り.md` の「予定」で、過ぎたのに「済」になっていない行

## 4. 係のむだ
- `roles/roster.md` の係の数と、`org/decisions.md`・`status/` から「この1か月で呼んだか」を見る。使っていない係は、残すか消すかを聞く（消すのはカードと名簿の行。消す前に聞く）
- 同じ事実が2か所に書いてある所（1つの事実は1か所）
- 点検係（`roles/点検係.md`）を呼ぶかを聞く。おすすめは「大きく動いた月は呼ぶ、静かな月は呼ばない」（呼ぶと使用量を使うから）

## 5. 片付け
- `work/`（係の返事の本文。Git に入らない）は、本人が消す（秘書は消せない決まり）。消すなら PowerShell で：
  `cd $HOME\notes; Get-ChildItem work -Exclude README.md | Remove-Item -Recurse -Force`
  （`$HOME\notes` は秘書のフォルダ。違う場所ならそのパスにして出す。消す前に中を見たければ `explorer work`）

## 6. まとめて残す
- 本人への報告：「見つけた物」「本人がやること（打つ1行があればそのまま）」「秘書がやったこと」を短く
- `org/decisions.md` に1行：日付・点検した・見つけた物の数・直した物
- 保存（commit・push）

## やらないこと
- `.claude/` の中・`CLAUDE.md` を自分で直さない（何をどう直すかを書いて本人に渡す）
- 作業場の中を直さない
- 本人に聞かずに係・status の行を消さない
